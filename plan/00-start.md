# Як почати

Це новий, окремий проєкт від Task Management API — потрібна нова папка.

1. Створи нову порожню папку, наприклад `reformulation-assistant`.
2. Поклади туди файл `CLAUDE.md` (з цього ж завантаження).
3. Створи в цій папці підпапку `plan/` і поклади туди всі файли з `01-...` по `07-...`.
4. Відкрий термінал у цій папці (той самий спосіб, що й минулого разу — `cd` і перетягнути
   папку в термінал, або клікнути правою кнопкою → відкрити термінал тут).
5. Підключи порожній репозиторій на GitHub ще до старту Claude Code:
   ```
   git init
   git branch -M main
   git remote add origin https://github.com/zarovnyi22/pet.git
   ```
   (репозиторій `zarovnyi22/pet` має вже існувати на GitHub і бути порожнім — якщо ще не
   створював його там, створи зараз, без README/gitignore від GitHub, щоб не було конфлікту
   при першому пуші).
6. Запусти `claude` (Claude Code вже встановлений з минулого разу, повторно ставити не треба).
7. Підтверди довіру до нової папки, коли запитає.
8. Йди по файлах `plan/01-skeleton.md` → `plan/07-bonuses.md` по черзі, один блок за раз.
   Не давай наступний промпт, поки не пройшла контрольна точка попереднього. Кожен промпт
   уже містить в кінці прохання закоммітити і запушити — Claude Code сам буде пушити в
   `https://github.com/zarovnyi22/pet.git` після кожного блоку.

## Ключі LLM (Gemini і Groq)

Не встав їх сюди в чат і не клади в CLAUDE.md — це не те місце. Коли дійдеш до
`plan/01-skeleton.md`, там буде створено `.env.example` з назвами змінних
(`GEMINI_API_KEY`, `GROQ_API_KEY`). Скопіюй його в `.env` (`cp .env.example .env`) і встав
реальні значення ключів туди, вже у себе на комп'ютері, руками, в тому ж редакторі, де
відкриється файл. `.env` в `.gitignore`, тому нікуди далі не потрапить.

Ключі отримуються тут (безкоштовно, без картки):
- Gemini: Google AI Studio — https://aistudio.google.com/apikey
- Groq: https://console.groq.com/keys

## Загальні правила на весь день

- Один блок плану — один промпт, одна контрольна точка, один коміт і пуш. Не проси "зроби
  все одразу".
- Не давай наступний промпт, поки Claude Code реально не запушив попередній коміт (перевір
  `git log --oneline -1` і що на GitHub у репозиторії `zarovnyi22/pet` з'явився новий коміт).
- Не вір "готово" на слово — виконуй curl/команду з контрольної точки сам.
- Коли щось падає — вставляй Claude Code повний traceback, а не переказ своїми словами.
- Якщо незрозуміло чому обрано якесь рішення (hnsw, asyncpg, косинусна відстань) — прямо
  питай "поясни чому X, а не Y" в Claude Code. Це і є підготовка до співбесіди.
