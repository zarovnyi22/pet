# Блок 2 — Дані і інгест (орієнтир: 1 година)

Цей блок — два окремі промпти: спершу корпус документів, потім сам pipeline інгесту.

## Промпт 2a — генерація корпусу

```
Згенеруй 20 markdown-документів у папку data/corpus/ згідно з CLAUDE.md:
- 12 файлів doc_type: ingredient_spec (функція інгредієнта, дозування, алергени, нутрієнти
  на 100г, чим можна замінити і застереження)
- 6 файлів doc_type: trial_report (що замінили, як змінилась текстура і смак, оцінка
  сенсорної панелі, висновок)
- 2 файли doc_type: guideline (політика з алергенів, правила зниження цукру без втрати
  об'єму)

Кожен файл 200-500 слів, з frontmatter doc_id, title, doc_type. Інгредієнти мають покривати
всі три цілі агента: молоко і рослинні аналоги, цукор і підсолоджувачі, яйце і замінники,
пшеничне борошно і безглютенові суміші. Документи мають містити конкретні числа (відсотки,
грами, температури) і конкретні пропозиції замін, не загальні фрази.
```

**Перевір сам:** відкрий 2-3 файли з різних doc_type і прочитай очима. Якщо там немає
конкретних чисел і конкретних замін — RAG пізніше не матиме що цитувати, поверни Claude Code
на доопрацювання зараз, а не після того, як збудуєш на цьому весь /ask.

## Промпт 2b — pipeline інгесту

```
Прочитай CLAUDE.md. Реалізуй:
1. app/chunking.py — чиста функція різання тексту на чанки по 400 токенів з перекриттям 50
2. app/embeddings.py — обгортка над sentence-transformers (all-MiniLM-L6-v2, 384 виміри)
3. POST /documents — приймає {doc_id, title, doc_type, content}, ріже на чанки, рахує
   ембединги, зберігає в БД. Повторний інгест того самого doc_id замінює старі чанки, не
   додає дублікати.
4. CLI-команда python -m app.ingest data/corpus/, яка проходить по всіх .md файлах у папці
   і заливає їх через ту саму логіку, що й POST /documents.

Прогони CLI на всій папці data/corpus/ і покажи, скільки рядків з'явилось у таблиці chunks.

Коли скажу, що контрольна точка пройдена — закоммить усе з повідомленням "Block 2: corpus and
ingest pipeline" і запуш у `origin main`.
```

## Перевір, перш ніж йти далі

- `python -m app.ingest data/corpus/` (або через `docker compose exec api ...`, як скаже
  Claude Code) відпрацював без помилок
- У таблиці `chunks` приблизно 100 рядків (20 документів × кілька чанків кожен)
- Запусти CLI ще раз на тій самій папці — кількість рядків у `chunks` НЕ повинна подвоїтись
