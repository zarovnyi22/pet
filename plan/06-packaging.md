# Блок 6 — Пакетування (орієнтир: 1 година)

## Промпт для Claude Code

```
Прочитай CLAUDE.md. Зроби фінальне пакетування:
1. Перевір і доведи до ладу Dockerfile (двостадійний, модель ембедингів вантажиться на
   етапі збірки образу, не при старті контейнера) і docker-compose.yml
2. Makefile з короткими командами (up, down, test, ingest, lint)
3. README.md із шістьма блоками:
   - що це і для кого
   - архітектурна схема в mermaid
   - як запустити за 3 команди
   - приклади curl на кожен з чотирьох endpoints
   - як працює агент, з прикладом trace
   - "що б зробив далі" (3-5 пунктів)
4. Перевір структурні JSON-логи через стандартний logging з request_id, який прокидається
   в логи агента

Коли скажу, що контрольна точка пройдена — закоммить усе з повідомленням "Block 6: packaging
and docs" і запуш у `origin main`.

Після цього візьми весь наявний git-репозиторій, перевір git log — має бути читабельна
історія, приблизно один коміт на блок плану (Скелет, Інгест, RAG, Агент, Тести,
Пакетування), а не один коміт на весь день. Якщо історія не така — не переписуй її заново
без мого дозволу, просто скажи мені, як зараз виглядає git log, і я скажу що робити.
```

## Перевір, перш ніж йти далі

Найкраща перевірка — зроби те, що зробить перевіряючий: клонуй репозиторій в окрему чисту
папку і запусти рівно за інструкцією з README, без жодних підказок від Claude Code:

```
git clone <твій репозиторій> /tmp/clean-check
cd /tmp/clean-check
cp .env.example .env   # встав свої реальні ключі
docker compose up --build
curl http://localhost:8000/health
```

Якщо це спрацювало без жодного додаткового кроку, якого нема в README — блок пройдено.
Відкрий також `/docs` у браузері — Swagger має показувати всі чотири endpoints з прикладами
тіл запитів.

Основний скоуп проєкту на цьому завершено. Бонуси — `plan/07-bonuses.md`, робити тільки
після цього чекпоінту.
